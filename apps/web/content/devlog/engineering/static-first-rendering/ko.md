---

읽기 전용 사이트에서 서버가 매 요청마다 할 일은 거의 없습니다. 글은 이미 정해져 있고, 사용자는 로그인하지 않으며, 개인화할 것도 없습니다. 그런데도 많은 사이트가 요청 시점에 데이터베이스를 두드립니다.

## 빌드 시점에 확정되는 것들

우리가 빌드 때 확정하는 값은 세 가지입니다.

- 어떤 글이 존재하는가 — 파일 시스템을 한 번 훑으면 끝납니다.
- 각 글이 어떤 언어로 제공되는가 — `{locale}.md` 존재 여부로 결정합니다.
- 글이 어떤 폴더에 속하는가 — 디렉터리 경로가 그대로 계층이 됩니다.

세 가지 모두 요청과 무관하므로, 요청 시점에 다시 계산할 이유가 없습니다.

## 예산은 어디로 가는가

정적 렌더링을 기본값으로 두면 서버 비용이 거의 0에 수렴합니다. 그렇게 아낀 예산은 이미지 품질, 번역, 그리고 글 자체에 씁니다. 인프라를 자랑하는 대신 콘텐츠를 자랑하는 쪽이 낫습니다.

> 계산할 수 있는 것은 미리 계산한다. 나머지는 브라우저가 한다.
