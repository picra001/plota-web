폴더에 속하지 않은 글은 섹션 최상단에 둡니다. 사이드바에서는 폴더 목록 아래, 목록 페이지에서는 그룹 섹션 뒤에 표시됩니다.

## 2026.08

- 왼쪽 계층 목차 추가. 폴더는 접고 펼 수 있으며, 마지막 상태를 기억합니다.
- 글 사이 이동을 목차 순서 기준의 이전/다음 링크로 연결했습니다.
- 상세 페이지 상단에 현재 글이 속한 폴더 경로를 표시합니다.

## 2026.07

- 콘텐츠 디렉터리를 계층 구조로 전환했습니다.
- 정적 렌더링을 기본값으로 고정했습니다.
